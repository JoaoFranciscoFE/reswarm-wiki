# Tool models

![Tool models](img/Gummyballer.png){ .update-log-icon }

**Released:** September 13, 2026

New models for every tool and a new code.

## What's new

* **Every tool in the game has a new model.**
* Endgame collectors have an updated sticker.
* All [bags](bags.md) now show their buffs in your inventory and the buffs area with your equipment.
* Revealed some bags' hidden stats.

## Changes

* Melittology level 20+ requirements were lowered.

## Fixes

* Fixed a few bag stats that should have applied but did not.

## Codes

| Code | Reward | Status |
|---|---|---|
| `ChickenBee` | A sticker, 1.5x capacity for 15 minutes, 1.5x honey for 15 minutes, 300 [Sunflower Seeds](sunflower-seed.md) and 10x Mondo Blessing | Active |
