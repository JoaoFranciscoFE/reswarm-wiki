# Mythic Jelly

![Mythic Jelly](img/Mythic_Jelly.png){ align=right width=150 }

*"Always transforms a bee into a random Mythic!"*

**Mythic Jelly** is a jelly that, when used on a [bee](bees.md), always turns it into a random [Mythic bee](bees-mythic.md). It uses the same icon as [Royal Jelly](royal-jelly.md).

## Ways to obtain

* A rare prize from [Memory Match](memory-match.md). Loot multipliers never change how many you get.
