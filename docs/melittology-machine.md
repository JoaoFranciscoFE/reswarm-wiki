# Melittology Machine

![Melittology Machine](img/places/Melittology_Machine.png){ .wiki-photo }

The **Melittology Machine** opens the [Melittology](melittology.md) tree. It's on the yellow ledge on the [mountain top](mountain-top-field.md), near the [Boost Market](boost-market.md) and [Onett's Lid Art](onett-s-lid-art.md), right next to the [Melittology Quests](melittology-quest-giver.md) pad.

The machine is a big glass light bulb with a smiling cube inside, on a yellow and blue base with red-tipped rods. Its pad reads **"Melittology Tree"**.

## Usage

* The prompt is **"Open the Melittology Tree"**.
* It needs [Rebirth 10](rebirths.md).
* Using it opens the Melittology tree screen, where you spend [Research Points](research-points.md). There's no cooldown.
* You can also open the tree from the **Melittology Tree** tile in your Boosts bar.
