# King Beetle Amulet/Probability

King Beetle Amulets always drop at maximum quality, and every [King Beetle](king-beetle.md) kill gives one, so there is no quality breakdown for this amulet. See [King Beetle Amulet](king-beetle-amulet.md) for the stats it can roll.
