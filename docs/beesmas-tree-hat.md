*Not to be confused with [Beesmas Tree](beesmas-tree.md), a Beesmas-exclusive location of a similar name.*

A **Beesmas Tree Hat** is a [level](bond.md) 10 Beesmas [beequip](beequip.md). It has an equip limit of three. There is no color requirement. It can only be equipped to [bees](bees.md) with a [mutation](mutation.md).
