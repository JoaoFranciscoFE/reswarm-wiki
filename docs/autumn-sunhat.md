The **Autumn Sunhat** is a [level](bond.md) 16 [Beequip](beequip.md). It has an equip limit of one. There is no color requirement. It can only be equipped to [Hasty](hasty-bee.md), [Bumble](bumble-bee.md), [Looker](looker-bee.md), [Exhausted](exhausted-bee.md), [Diamond](diamond-bee.md) and [Puppy](puppy-bee.md) [Bees](bees.md).
