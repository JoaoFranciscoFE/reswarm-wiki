# Gummy Cannon

This piece of content goes bye bye.

The following content has been removed from the game. The contents below may be archival, but feel free to edit below.

The **Gummy Cannon** is [Gummy Bear's](gummy-bear.md) personal cannon that he used to fire [gumdrops](gumdrops.md) onto [fields](fields.md). It was brought to the mountain in the [2018-05-26](updates.md#2018-05-26) update and was removed alongside Gummy Bear at a later date. The Gummy Cannon's color scheme is identical to the color of [goo](goo.md), gumdrops, [Gummy Bee](gummy-bee.md), and Gummy Bear, with a teal base and a pink barrel. It was found next to Gummy Bear and Gummy Bee.

When Gummy Bear launched the cannon, all players in the server would get a notification that said:
Sights Set on the [Field Name]!

Gumdrops would be scattered all over the selected field until the field changed.

Starting in Beesmas 2020 and returning each Beesmas after, it is summoned by using the [Gummy Beacon](gummy-beacon.md) to summon a Gummy Siege after completing Gummy Bear's [Beesmas Quest](gummy-bear.md#2021_Beesmas_Quest_-_Gummy_Beacon). Each time gumdrops are scattered on a field, a gumdrops token appear in its place.

## Trivia

* The Gummy Cannon is the only cannon that wasn't used for player transportation. It is only used for decoration.
  * It is also the first and only cannon to launch [items](items.md).
* When the Gummy Cannon launches gumdrops, the animation of the gumdrops falling onto the selected field is the same one as the player using gumdrops in the field.
* The Gummy Cannon is not completely accurate; the gumdrops it launched could miss the fields it aims at, and possibly even splatter goo into nearby fields.
* This is the only cannon that was removed in-game and returned.
* The cannon shoots 5-7 gumdrops before aiming at other fields.
* There used to be a gumdrop token behind the cannon.
  * After the event ended, the gumdrop token was covered with a green path, which made it more difficult to get, although it is possible to get it if the player moves along the edge.
