# Ant Field

20 bees

Invigorating Nectar

FIELD DIMENSIONS

32 × 12 flowers

FLOWER COUNT

384

BEE PREFERENCES

LIKE

DISLIKE

None

The **Ant Field** is a [field](fields.md) located past the [Ant Gate](ant-gate.md) and near the Top Ant Exterminators leaderboard. It can only be accessed by starting the [Ant Challenge](ant-challenge.md) which will summon waves of [ants](ants.md).

This field can produce [honey](honey.md) and [ticket](ticket.md) tokens while collecting [pollen](pollen.md).

The only [bee](bees.md) that likes the Ant Field is [Lion Bee](lion-bee.md). There are no bees that dislike the Ant Field.

[Planters](planter.md) cannot be planted in this field, although Onett has stated that the Ant Field contains [Invigorating Nectar](nectar.md).

This is a 12×32 field, containing 384 [flowers](flowers.md). The flowers are white, red, and blue, and the only natural size in single.

## Obtaining Boosts

* Using an [Ant Pass](ant-pass.md) to start the Ant Challenge will give 100% Instant Ant Field Conversion.
* There is no possible to way to boost the pollen for the Ant Field.
* The flowers can still be [pollinated](pollination.md).

## Trivia

* You can collect pollen from the Ant Field outside the challenge by using the [Sticker-Seeker](sticker-seeker.md) or spawning [flames](flame.md) with the [Scythe](scythe.md).
* The Ant Field is the only [field](fields.md) that does not have its own [badge](badges.md), ignoring fields existing only in challenges like [Red Brick Field](red-brick-field.md).
* [Lion Bee](lion-bee.md) is the only bee to like the Ant Field; all other bees are neutral to this field.
* The Ant Field is the only field to have exclusively single [flowers](flowers.md).
  * The flowers on this field contain 50 pollen per flower, and instead of going up by 15 pollen per tier, go up 10 per [pollination](pollination.md) tier up to 90, although pollen multiplier remains the same as regular flowers.
* The Ant Field is the only field that can't be boosted with [glitter](glitter.md), the only field where a [magic bean](magic-bean.md) cannot be planted, the only field where clouds cannot be summoned, the only field that had no Market Boost from the [Boost Market](boost-market.md), the only field that can't get [winds](field-wind.md) from the [Wind Shrine](wind-shrine.md), and the only field where [planters](planter.md) cannot be planted.
* The Ant Field is the smallest field in the game with 384 flowers, smaller than the [Pumpkin Patch](pumpkin-patch.md) with 561 flowers and the [Stump Field](stump-field.md) with 563 flowers.
* The Ant Field is one of the 5 fields that are exclusively used for a challenge. The other others include the [Mixed Brick Field](mixed-brick-field.md), [White Brick Field](white-brick-field.md), [Blue Brick Field](blue-brick-field.md) and [Red Brick Field](red-brick-field.md).
* Players are able to glitch into the Ant Field without triggering the actual challenge. This can only be achieved by having a slow internet connection or [bear morph](ability-tokens.md#Bear_Morph) and/or [haste+](buffs-debuffs.md#From_Areas).
* Despite being impossible to boost, the Ant Field has an unused [Field Boost](field-boost.md) icon.
