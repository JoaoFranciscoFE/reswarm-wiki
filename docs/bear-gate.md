The **Bear Gate**, also known as the **30 Bee Gate**, is a gate added in the 2018-7-11 update that requires 30 [bees](bees.md) to pass through. It is located past the [Mountain Top Field](mountain-top-field.md), between the [Ticket Shop](ticket-shop.md) and the Mountain Top [Instant Converter](instant-converter.md). Two quest-giving NPCs reside here, that being [Onett](onett.md) and [Bubble Bee Man](bubble-bee-man.md).

Underneath the platform in the gate, there is a [Diamond Egg](egg.md#Diamond_Egg) token and [Shadow Bear](shadow-bear.md) behind it. To reach the egg token, equip either the [Parachute](parachute.md) or the [Glider](glider.md). Touching the floor kills the player, so it is advised to have an empty container before attempting to reach the [Diamond Egg](egg.md#Diamond_Egg).

## Trivia

* The Bear Gate is the largest gate in the game in terms of size.
* The Bear Gate requires the second largest number of bees to pass through, only behind the Windy Bee Gate.
* During Beesmas, the Bear Gate has a gigantic star on top of it.
* This is the only gate that does not have a [field](fields.md) behind it. It is also the only gate without the requirement pad and the egg sign, and the only gate without a blue arch around it.
* This gate, along with the [Windy Bee Gate](windy-bee-gate.md) and the [Ant Gate](ant-gate.md), are the only gates in the game that didn't exist at launch. These three gates, along with the [Brave Bee Gate](brave-bee-gate.md), also don't lead to any other gate in the game.
* This gate and the Windy Bee Gate are the only gates where buying [hive slots](hive-slot.md) is a requirement to pass through them.
* This gate, along with the Ant Gate, are only gates that do not have a bee model on top of it.
* The area beyond the gate is indoors, not outdoors. This means that even though there appears to be an opening to the sky, it is blocked by an invisible barrier because otherwise, it would be accessible through the [Red Cannon](red-cannon.md).
* The player used to be able to get into the Bear Gate's crown, but this has been patched.
* There used to be a glitch where if the player respawned and ran to the red cannon, they could use the Cannon to enter the gate without dying if they were quick enough using the [forcefield](https://developer.roblox.com/en-us/api-reference/class/ForceField) applied on respawn. This glitch has since been patched.
* The [Boost Market](boost-market.md) used to be inside the Bear Gate. It was replaced by the [Nectar Pot](nectar-pot.md) on the 2021-26-12 update.
* Previously, the [Red Cannon](red-cannon.md) used to be able to shoot the player high enough for them to be able to land on top of the gate. The red cannon's angle has since been lowered, making this impossible.
