# BSS Staff

<figure class="thumb mw-halign-right" style="width: 180px" typeof="mw:File/Thumb">  <figcaption class="thumbcaption"> </figcaption> </figure>

Below is a list of current staff members for the [Bee Swarm Simulator Discord Server](https://discord.gg/bee). The staff members of the Discord server are not in-game moderators.

Onett and the Server Managers are not actively involved in server moderation. If you have a question about your moderations, please DM a moderator or use the server's ticket system. If you have been banned from the server, you may submit an appeal [here](https://dyno.gg/form/fd4f608d). Users may only appeal once. *There is no way to appeal an in-game ban.*
