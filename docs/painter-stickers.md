# Painter Stickers

The **Painter stickers** are a set of [stickers](sticker.md) added in the [Painter Bee event](painter-bee-event.md).

## The stickers

| Sticker | Notes |
|---|---|
| Red Paint Splatter | One of the three splatters |
| Blue Paint Splatter | One of the three splatters |
| White Paint Splatter | One of the three splatters |
| Painter's Doodle | Made by stacking the three splatters |
| Painter Bee Painting | |
| Gifted Painter Bee | |
| Supreme Puffshroom | Themed on the new [Supreme Puffshroom](supreme-puffshroom.md) |

The code `splat!` gives a random Paint Splatter (see [Codes](codes.md)).

## Stacking rewards

Stacking these on the [Sticker Stack](sticker-stack.md) unlocks two rewards:

* **Painter's Doodle:** stack all three Paint Splatters (Red, Blue and White).
* **Painter Bee's Artistic Hive Skin:** stack all six Painter stickers. The hive skin includes an easel that shows the hive owner's Roblox avatar headshot.
