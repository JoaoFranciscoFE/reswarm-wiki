# Sprinkler Builder

![Sprinkler Builder](img/Sprinkler_Builder.png){ align=right width=150 }

*"Use while standing in flowers to place a Sprinkler."*

The **Sprinkler Builder** is a permanent inventory item. Use it while standing in a field to place your [sprinkler](sprinklers.md). It has no use cooldown.

## Ways to obtain

* Every player starts with one. You can only have 1.
