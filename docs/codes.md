# Codes

Promo **codes** can be redeemed in Re://:Swarm for prizes such as items and boosts.

Codes from [Bee Swarm Simulator](re-swarm.md) do not carry over to Re://:Swarm. Only the codes below are known to belong to Re://:Swarm.

## Currently Valid Codes

| Code | Reward |
|---|---|
| splat! | Chicken's Blessing and a random Paint Splatter sticker (Red, Blue or White) |
