# Painter Bee update

**Released:** October 2, 2026

The [Painter Bee Event](painter-bee-event.md): a new bee, new flowers, a new wax and a new Puffshroom tier.

## What's new

* **New bee: [Painter Bee](painter-bee.md)**, a Colorless Event bee obtained from Rebirth 35, the Robux pack, and later the Painter Bee Voucher once the pack is gone.
    * Ability **Paint Splat!**: changes 12 flowers to the set color and pollinates them.
    * Gifted ability **Painter's Haze**: randomly pollinates 3x3 areas in the field and changes them to the chosen color.
    * New passive **Paint Residue**: any flower the bee gathers from gets pollinated and painted.
* **New pack: Painter Bee's Colorful Haul**, with a 1st Edition Painter Bee Voucher, each Color Splat sticker, Painter Bee's Hive Skin, both Painter Bee stickers and Painter's Doodle. See [Painter Stickers](painter-stickers.md).
* **All new flowers:** every field flower has been redrawn.
* **New wax: [Fluxite Wax](fluxite-wax.md)**, which rerolls a [Beequip](beequip.md)'s potential from 1 to 5 stars. Get it as a 1/10 drop from Supreme Sprouts, by crafting, or with Robux.
* **New Puffshroom tier: [Supreme Puffshroom](supreme-puffshroom.md)**, above Mythic, with a 1/100 chance to drop a sticker of itself.
* New performance setting: hide [Puffshrooms](puffshroom.md) below a chosen rarity (also hides the flying spores).

## Changes

* [Mortar Bee](mortar-bee.md)'s shell blast now collects any tokens inside it.
* Painter Bee buff: if a flower is already your color and at max tier, the paint picks a random flower instead.
* If an item in your inventory hits zero, its auto-use turns off (so it can always be turned off).
* The `celebration!` code was removed.

## Fixes

* Fixed bees visually desyncing or standing still for no reason.
* Fixed discard sticker tasks.
* Fixed Feed Bee quests at large treat numbers.
