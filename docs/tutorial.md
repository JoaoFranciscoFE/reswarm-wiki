# Tutorial

The **Tutorial** in Re://:Swarm is a guided **walkthrough** that shows new players how to play by having them do each step in the game. It replaces the old picture-book tutorial from Bee Swarm Simulator, where players flipped through pages in a menu.

## Starting the walkthrough

New players are not dropped into the tutorial as soon as the game loads:

1. Claim a [hive](hive.md).
2. Talk to [Onett](onett.md), who welcomes you with a Honeyday gift.
3. When Onett's welcome closes, the game asks *"You look new here! Want to do the tutorial?"* Choose whether to start the walkthrough.

While any NPC conversation is open, the walkthrough's dialog panel hides itself so it does not cover the conversation.
