# Memory Match

This piece of content contains information obtained through datamining.

Due to the nature of the information, details may be inaccurate or outdated.

Datamined information: The probability of finding every possible reward. — December 19th, 2024

**Memory Match** is a match-style minigame located in various places throughout the map. The goal is to match as many pairs as possible to win [items](items.md). There are four (five during Beesmas) of these machines that can be used. Each machine costs a varying amount of [honey](honey.md). (See below.)

## Gameplay

<figure class="thumb" style="width: 180px" typeof="mw:File/Thumb">  <figcaption class="thumbcaption"> <p class="caption">The Night Memory Match Screen. An example of a board of size 4x4 cards.</p> </figcaption> </figure>

<figure class="thumb" style="width: 180px" typeof="mw:File/Thumb">  <figcaption class="thumbcaption"> <p class="caption">The Extreme Memory Match screen. An example of a board of size 4x5 cards.</p> </figcaption> </figure>

When activated, a screen will pop up with a board of size 4x4 or 4x5 grids. A player has a limited number of chances to match cards together. Matching a pair also costs a chance. They can gain more chances if they have the required certain ranks of [field badges](badges.md) to get it.

Machines with rarer rewards require more honey and a higher badge rank for extra chances. They also have a longer cooldown between each activation.

If at least one match is made, a message will appear in the chat:
Winner!, with the items matched and the amount listed below.

If no matches are made, a message will appear in the chat: 
Better luck next time!

## Machines

Currently, five memory match types can be accessed at any time.   
There's also a memory match that is started upon receiving certain quests.

## Trivia

* The Extreme Memory Match is the biggest Memory Match machine in terms of the "computer" model size. It is also the most expensive machine in terms of honey.
* If the player started a new memory match game while one was already active, the new game would not have started, but the player still had to pay the fee and wait for the cooldown. This is no longer possible because the player's movespeed is set to zero during a memory match game.
  * The player can still move during the minigame by using the [Parachute](parachute.md) or [Glider](glider.md).
* The Winter Memory Match is the only machine that can only be accessed during an event and requires the completion of a quest to use, namely [Spirit Bear's quest for that Beesmas](spirit-bear.md#Beesmas_Quests).
* The Winter Memory Match had an unusual bug where if the player did not have enough snowflakes, trying to use the machine displayed the message:

and Complete 1 Quest to You need 100 Snowflakes to play Winter Memory Match.

* Assuming there are no duplicate pairs and the player is playing optimally, the chances of getting any prizes in a Memory Match for each board size is:
  * For 4x4: about 37% for 3 chances, 46% for 4 chances, 54% for 5 chances, and 60% for 6 chances.
  * For 4x5: about 45% chance to reward the player if they receive 5 chances, 51% for 6 chances, 56% for 7 chances, and 61% for 8 chances.
