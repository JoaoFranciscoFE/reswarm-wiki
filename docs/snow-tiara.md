A **Snow Tiara** is a [level](bond.md) 12 Beesmas [beequip](beequip.md). It has an equip limit of one. There is no color requirement. It can only be equipped to [Cool](cool-bee.md), [Stubborn](stubborn-bee.md), [Shocked](shocked-bee.md), [Frosty](frosty-bee.md), [Diamond](diamond-bee.md), and [Windy](windy-bee.md) [Bees](bees.md). The bee must be [gifted](gifted-bee.md) for it to be equipped.
