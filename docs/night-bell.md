# Night Bell

Night Bell

*"Summons nighttime. A Moon Sprout and a Vicious Bee are guaranteed to appear."*

COOLDOWN

1 second

A **Night Bell** is an inventory item that was added in the 2018-12-25 update. When used, it summons [nighttime](day-night-cycle.md), along with a [Moon Sprout](sprout.md) and a [Rogue Vicious Bee](rogue-vicious-bee.md).

Whenever a player activates a night bell, the sound of a bell chiming will play and a server-wide message will appear, saying:

🌙 {Username} has summoned nighttime... 🌙

<figure class="thumb" style="width: 500px" typeof="mw:File/Thumb">  <figcaption class="thumbcaption"> <p class="caption">The server-wide message when a player in the server uses a night bell.</p> </figcaption> </figure>

Upon using a night bell, the server will receive the public announcement above, along with the following sound file below.

## Ways to Obtain

* As a rare drop from certain mobs:
  * [Werewolf](werewolf.md)
  * [King Beetle](king-beetle.md)
  * [Wild Windy Bee](wild-windy-bee.md)
  * [Fireflies](fireflies.md)
  * [Coconut Crab](coconut-crab.md)
  * [Tunnel Bear](tunnel-bear.md)
* As a reward from Memory Matches.
  * A rare reward from [Night Memory Match](memory-match.md#Night_Memory_Match).
  * As a rare reward from Winter Memory Match.
* Buying them from the [Robux Shop](robux-shop.md) for 80 Robux each.
* As a Playtime Master [Badge](badges.md) reward from donating [Enzymes](enzymes.md) to the [Wind Shrine](wind-shrine.md).
* Completing [Spirit Bear](spirit-bear.md)'s "Do You Bee-lieve In Magic?" quest rewards 1 night bell.
* As a rare drop from a [Festive Planter](festive-planter.md).
* As a rare drop from [Stockings](stockings.md).
* As a rare drop from [Festive Nymphs](festive-nymph.md).

## Trivia

* Using a Night Bell when it is already nighttime results in a message that says “You can only use Night Bells during the day.”
* If you summon nighttime right after nighttime ends a new set of fireflies will be spawned when you can see the other fireflies fly away.
  * The sky will also flash if you summon nighttime even quicker (when the sky is changing from night to day).
* Night Bells and [Boxes-O-Frogs](box-o-frogs.md) are the only two consumable items that summon mobs.
  * The Night Bell summons two types of mobs, [Fireflies](fireflies.md) and [Rogue Vicious Bee](rogue-vicious-bee.md).
